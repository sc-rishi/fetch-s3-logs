Fetch S3 Logs Control Panel

This UI mirrors the fetch-s3-logs.js job: list S3 objects, download with controlled concurrency, apply optional text/field/time filters, normalize output, and keep track of progress.

How the job works

  • Lists objects under a bucket/prefix (optionally scoped with --dir, --start-after, --max-keys).
  • Streams each object, gunzips when required, and extracts raw/filtered log lines.
  • Supports substring matching, structured field equals, or OR-of-AND expressions for JSON payloads.
  • Filters by JSON time field using UTC or IST inputs and can sort by time ascending/descending.
  • Writes prettified JSON per S3 object into your local output directory and reports missing matches.

Provide either a full S3 URL or a bucket + prefix. The region is pinned to ap-south-1, matching the CLI script.
